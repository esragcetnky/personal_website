# Esra Gül Çetinkaya — Personal Website

Personal portfolio website built with vanilla HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Live Site

[esragcetnky.github.io/personal_website](https://esragcetnky.github.io/personal_website)

## Sections

- **About** — Short bio and background
- **Experience** — Work history with timeline (Enerjisa Corporation, VISEA Innovative)
- **Projects** — Featured technical projects (MultiBot Hub, Turkish Voicebot, DiT-Base Image Similarity)
- **Skills** — Programming, ML/AI, cloud platforms, and MLOps tools
- **Contact** — Email and social links

## Tech Stack

| Layer | Choice |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, grid, flexbox) |
| Behaviour | Vanilla JavaScript |
| Hosting | GitHub Pages |

## Local Development

No build step needed — open `index.html` directly in a browser or serve with any static file server:

```bash
npx serve .
# or
python -m http.server
```

## Deployment

The site is deployed automatically via GitHub Pages. Any push to `main` triggers a redeploy.

To enable GitHub Pages on a fork:
1. Go to **Settings → Pages**
2. Set source branch to `main`, folder to `/` (root)
3. Save — the site will be live at `https://<username>.github.io/<repo>`
